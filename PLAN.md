# План выполнения тестового задания Startup Exchange

## Цель

Создать работающий прототип модуля стартапов и вакансий для Telegram Mini App: backend на Python, PostgreSQL, адаптивный frontend и запуск через Docker Compose.

## Основной сценарий

1. Пользователь входит под тестовым аккаунтом.
2. Создаёт публикацию типа «стартап» или «вакансия».
3. Другой пользователь видит публикацию в ленте и отправляет отклик.
4. Автор публикации принимает или отклоняет отклик.
5. Откликнувшийся видит результат в личном кабинете.

## Решения

- Backend: FastAPI, SQLAlchemy 2, Alembic, Pydantic.
- Database: PostgreSQL.
- Frontend: React, TypeScript, Vite.
- Infrastructure: Docker Compose.
- Authentication: JWT demo sessions with access control.
- Testing: pytest API/integration tests and frontend production build.

## Этапы

1. Подготовить чистую структуру проекта, Docker Compose, окружение и README.
2. Реализовать модели пользователей, профилей, публикаций и откликов, миграции и seed-данные.
3. Реализовать авторизацию, API ленты, публикаций, откликов и личного кабинета с проверками прав.
4. Создать адаптивный React-интерфейс для входа, ленты, публикаций и кабинета.
5. Добавить тесты полного сценария, повторных действий, ошибок и разграничения доступа.
6. Провести Docker smoke-check, обновить документацию и опубликовать все атомарные коммиты.

## Критерии готовности

- Два тестовых аккаунта проходят полный сценарий публикации и отклика.
- Данные сохраняются в PostgreSQL.
- Нельзя повторно отправить отклик или откликнуться на свою публикацию.
- Только автор публикации меняет статус отклика.
- Реализованы загрузка, ошибки и пустые состояния интерфейса.
- Проект запускается через Docker Compose.
- README содержит запуск, аккаунты, решения, AI-практики и фактически потраченное время.

## Допущения

- Telegram WebApp SDK не подключается в обязательном прототипе; UI остаётся совместимым с последующей интеграцией.
- Реальные Telegram ID, внешние интеграции, загрузка файлов, уведомления, Redis и Kafka не входят в обязательный объём.
- Интернет-развёртывание является бонусом после стабильной локальной версии.
